Checked October 12, 2026: STAR WARS: Galactic Racer is Very Positive — 3,406 positive out of 4,011. Launch was October 6. The live PC price is $59.99. Forty-nine achievements. Fuse Games developed it. Secret Mode published it. First-day Steam concurrent players passed 15,400.

The praise is speed, crash, and the tour. Files call it Burnout-plus-F-Zero in the Outer Rim, or the best racing game in a decade. The complaint that survives is the same one the studio already answered: multiplayer group size is too small, crash playback runs long, and the planet list is short. A hotfix already raised minimum graphics drivers. A later note says group size will double. That is not in the build you bought on day one.

## How to read the first week

- Buy it for the combat tour, not for a ranked career. The [worth-it page](/is-it-worth-it/) is the fit.
- If online parties are the reason you waited, the doubling is a future update, not a hidden menu. See [cross-platform PvP](/cross-platform-pvp-status/).
- If the game refused to boot, check the driver floor in the hotfix before you refund. See [driver hotfix](/driver-hotfix/).

A sale does not add a private lobby. It changes whether $59.99 for this tour feels fair six days in.
