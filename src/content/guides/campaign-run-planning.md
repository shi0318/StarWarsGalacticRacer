A campaign tour is not a season you can reload. You pick an event, that pick stays, and enough crashes end the tour. Some perks come with you. The speeder you just tuned mostly does not.

## What a run actually is

- You play Shade. The target is Kestar Bool.
- Events branch. There is no turning back once one is chosen.
- Crash out too many times and you regroup, rebuild, and start again.
- Hibi's workshop is the checkpoint between events. That is where credits become resilience, afterburner, or a ramjet you are not ready for.
- Derven Acos is the arena the late tour and the multiplayer showdown both point at. It stacks the earlier planets' conditions. It is not a separate ruleset.

## What to write down

You still will not get a numbered event tree from the menu. Keep a card anyway, because the next tour will offer the same fork:

| Field | Write this |
| --- | --- |
| Event | The choice you cannot undo |
| Planet | Jakku, Ando Prime, Crait, Sentinel One, Lantaana, or the finale |
| Class | Landspeeder, bike, skim speeder — pods are a different event |
| Failure | Wall, acid, heat, freeze, or a shunt |
| Carry-over | The perk that was still there after the wreck-out |

## Risk order

1. Learn the planet in a landspeeder before you bring a bike.
2. Buy resilience before the acid planet, not after the first death there.
3. Do not stack a new class, a new planet, and a ramjet in the same fragile tour.
4. If the tour dies, change one thing. Repeating the same fork on the same glass bike is how people write angry reviews.
