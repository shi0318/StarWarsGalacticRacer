## Does Star Wars Galactic Racer support a controller?

Yes. Steam lists **Full Controller Support** for the game. That means the store supports a controller-first experience on PC, but the listing does not state whether every device uses the same button prompts or whether all remapping options are final.

The practical pre-release setup is simple: connect the controller before the first launch, keep Steam Input settings consistent while testing, and check the game's own options after the release build is installed. Do not copy a controller layout from another racing game and present it as an official binding.

## Is Galactic Racer multiplayer?

The Steam listing includes multiplayer-related features, and official game copy describes multiplayer/PvP and cross-platform multiplayer. The exact platform pairing, matchmaking rules, party size, and regional restrictions should still be checked against the live store and launch notes. This page is a Steam feature reference, not a final competitive rules guide.

## What this page does not claim

Full controller support does not prove support for every wheel, joystick, or unusual input device. Multiplayer wording does not by itself confirm cross-play details for every platform. Those claims need a device test or a specific first-party announcement. The game is still pre-release, so balance, controls, and platform services can change.
