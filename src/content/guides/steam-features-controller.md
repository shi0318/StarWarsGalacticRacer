The Steam page for App 4078430, now that the game is out, lists:

- Full controller support, and a gamepad is recommended
- DualShock and DualSense support
- Steam Cloud
- Steam Achievements
- Family Sharing
- Single-player, multiplayer, PvP, online PvP, cross-platform multiplayer
- Adjustable difficulty, subtitles, text size, camera comfort, and volume controls

## The part the store page oversells

"Full controller support" means a pad works. It does not mean the keyboard layout is comfortable, and it does not mean every bind can be moved in game. First-weekend reviews keep asking for in-game rebinding because accelerate, afterburner, drift, and ramjet want to be held at once. Until a patch adds that, put ramjet on a button you can reach, or stop using it in traffic.

Cloud saves the file. It does not add cross-progression rules the store page never published. Family Sharing follows Steam's normal rules for a paid game.

Install size and the GPU tier are on the [PC requirements page](/pc-requirements/).
