## Is there a demo, beta, or early access build?

**No.** As of our last check, neither Fuse Games nor Secret Mode has announced a demo, an open beta, a technical test, or early access. There is no playable build of this game in public circulation.

We spell that out because "star wars galactic racer download" is exactly the query that fake-installer and repack sites farm for unreleased games. If a site offers you a working download, an APK, or a "free full version", it is not distributing this game — no such public build exists.
