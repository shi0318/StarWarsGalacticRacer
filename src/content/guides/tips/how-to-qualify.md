A qualify attempt is not a combat tutorial. The event names the target. Your first job is to finish the lap without hitting the hazard that ends the run. The shunt comes after that lap is repeatable.

Kestar's qualify notes stay on [qualify for Kestar](/tips/qualify-for-kestar/). This page is the order for any event, so the two URLs are not the same article.

## Order

1. One clean lap. No contact. [Clean lap](/tips/one-clean-lap/).
2. Read the planet hazard and match the pod. [Pod to hazard](/tips/match-the-pod-to-the-hazard/).
3. Set the shunt up on the straight, and finish it before the apex. [Set up the shunt](/tips/set-up-the-shunt/).
4. If the lap hitches, stop. That is a driver or DLSS check, not a slower qualifying time.

Gold times stay on the event screen. Do not copy one into this page.
