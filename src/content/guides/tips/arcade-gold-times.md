An arcade gold is the target time on that event, shown by the event itself. It is not a number this site should invent, and it is not the same time on a reverse layout or a pod variant.

## How to chase one

- Run the event once without ramjet. The line is unmarked. A gold attempt on a first sighting is a crash.
- Use afterburner in the corners and ramjet only on a straight you have already survived.
- Pods have their own golds. A landspeeder time does not transfer.
- Deluxe trials have their own targets for the Kor Sarun hulls. Those times are not the base arcade list.

When you have a time from the event screen, that is the time. Until then, the [game modes page](/game-modes/) explains where Arcade sits. A copied "world record" from a video is not a target the game asked you to hit.
