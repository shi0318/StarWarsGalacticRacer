Searches for "how many tracks" want a single integer. The Steam page for **STAR WARS: Galactic Racer** does not print one. The honest guide is the list of circuits you can name and enter, plus the rule that a campaign tour and a multiplayer queue are not the same counter.

The game launched **October 6, 2026**, at **$59.99** on Steam, Very Positive at **7,372** of **8,494** reviews on October 20. Fuse Games shipped a league, not a spreadsheet. Bill Lane's October 20 note talks about Backers and rivals after you qualify. It does not say "there are N tracks." A guide that invents N to win the search is a guide that will be wrong on the next playlist update.

## What you can count

Count a track when you have entered it, or when this site's track page names it from a build you can open. Named circuits already written up here include ice, Tatooine, Jakku, Ando Prime, Crait, Mos Espa, and the Galactic Gauntlet and championship events. That is a directory, not a promise that the directory is the whole disc. If your menu shows a circuit this list does not, the menu wins. Add it to your own note. Do not subtract a circuit you have not visited because a thumbnail said the game is short.

Pods and speeders are separate queues. A pod event on a planet is not the same counter as a speeder lap on that planet. Players are still asking for a plain pod quick-race button. Do not assume the speeder queue includes Sebulba's grid. If you are counting "tracks I can race tonight," split the count by vehicle type. One planet can be two events.

The six-race tour is a mode, not six new planets. Upgrades between races, then a showdown, is the campaign loop with strangers in it. Counting the tour as six tracks and also counting each planet will double-count. Pick one counter and label it.

## What a number is not allowed to decide

It should not decide whether the game is worth **$59.99**. A short list of named planets can still be a long league if the contracts change the line. Vranki's jump, a rival's braking point, and a hazard the planet page names are the replay. A track count of "only eight" from a forum is not a refund reason until you have seen the menu.

It should not decide a trophy route. **49** achievements are on Steam. **Achievement10** was **92.3%**. Three rare ones in the October 20 global sample were **0.1%**. None of those names, in the data this page has, say "race every track." Open the in-game list. If a pop says visit a planet, visit that planet. Do not grind a guessed total.

It should not decide a Game Pass wait or a Switch 2 wait. Those platforms did not launch with the game. More tracks will not appear there until a store page does. Cross-play is across PC, PS5, and Xbox Series X|S. The track list is the same idea: three platforms, one set of circuits you can enter, no hidden Nintendo exclusive layout.

## How to use the directory

1. Open the [tracks hub](/tracks/) and enter one circuit you can already name.
2. Write down the hazard that made you crash. That hazard is more useful than a total.
3. Leave the draft before that hazard. A count of tracks does not exit a wake for you.
4. If a friend asks "how many," say the number you have entered, and say you have not finished the menu. That sentence ages better than a fake integer.

Minimum spec is an SSD, **50 GB**, and **12 GB** of RAM. A hitch on a new circuit is a load, not a missing track. Fix the disk before you decide the game hid a planet. The league is large enough to learn one braking marker tonight. The integer can wait until the menu and the directory agree.


## One more pass before you close the menu

The numbers on this page were checked against the October 20, 2026 Steam listing, not against a launch-week memory. Price, review count, achievement total, and the patch lines named above are the facts to plan a session around. A thumbnail that contradicts them is a thumbnail. Play the build you have. Write down the result in the game's own words. Then decide whether the next door, the next bind, or the next purchase is the one this page was about.

If the machine is under the minimum spec printed on the store page, fix that before you fix the tactic. An SSD requirement is a disk requirement. A RAM number is a RAM number. A driver popup is a driver popup. None of those become optional because a guide got longer. The tactic still matters after the machine holds a frame. It does not matter during a hitch you mistook for an enemy tell.

Stop when the one test in the list above has a yes or a no. A second system, a second cosmetic, and a second difficulty change in the same minute will make the yes useless. Come back for the second change after the first one is written down. The rest of the site can wait until that note exists.

Say the number you have entered. Label whether it is speeder, pod, or tour. Refuse the integer a thumbnail invented. The Steam page did not print a track total, and the October 20 Backers note did not either. Named circuits on this site are a directory you can open, not a census. If your menu has one more, the menu wins. If a friend asks tonight, the useful answer is the hazard that crashed you, not a guessed total. An SSD does not hide a planet. Enter one circuit, write the braking marker, and leave the count unfinished until the directory and the menu match.

The menu is the census. This page will not compete with it. Enter the next circuit when you can name the hazard, not when you need a round number.
