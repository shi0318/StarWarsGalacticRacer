A 0.9-hour file that otherwise loves the game names the leftover: Ray Reconstruction at 4K DLSS Balanced, about 110 fps, and still **a couple of tiny quasi-stutters** across multiple races. Not every race. Not a crash. Not the black screen between events.

The launch hotfix raised the **driver floor**, warned that the **first boot after an update rebuilds shaders** and takes longer, and made **DLSS options** more stable. If the hitch is only on first launch after a driver change, let that cache finish. If it still pops mid-race on a later session, it is not the boot check. See [driver hotfix](/driver-hotfix/).

## Split the three failures

- Boot refuse / long first load: driver floor and shader rebuild.
- Black screen between races, blown-out HDR: [HDR and black screens](/hdr-black-screens/).
- One-frame hitch in a later race at 100+ fps: this page. Do not drop every setting because of it, and do not file it as a missing private lobby.
