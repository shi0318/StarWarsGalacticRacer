The first **STAR WARS: Galactic Racer** quality-of-life update expanded online party size from **three players to six**. That makes it easier to bring a full group into multiplayer Tours, but a larger lobby also means it helps to agree on the vehicle class and event before everyone joins. The same update changed mid-Tour credits, added keyboard layout presets, and warned players to check campaign vehicle customization after installing. Use this guide to turn those changes into a smoother group session.

## Update before you invite the group

Make sure every player has installed the same current update before starting a party. If someone is still on an older version, they may fail to connect or see a different set of options. Restart the game after the update finishes, then check the online multiplayer menu. The party limit should allow up to six players rather than stopping at three.

Before launching a Tour, have the host identify whether the session is online multiplayer and what vehicle event the group is entering. A multiplayer Tour is not the same thing as a local Arcade practice. Knowing the event type helps the group choose a vehicle and understand whether campaign progression is involved. If one player wants to practice a track first, run an Arcade event separately, then return to the Tour when everyone is ready.

## Check campaign vehicle customization after installing

The update notice specifically asks players to check vehicle customization for the campaign because some instances of that data resetting were observed after installation. Before the next race, open the campaign garage and verify the livery, selected vehicle, and any customization you care about. If something looks different, set it again and confirm the change persists after leaving the garage.

Do not assume that a cosmetic reset means vehicle upgrades or campaign progress were erased. Check each category separately. If the game has returned a livery to a default option, reapply it; if a vehicle choice changed, confirm the class required for the next event before racing. A two-minute garage check is quicker than discovering the mismatch after the Tour has started.

## Agree on the event and vehicle before queuing

With six players, avoid a long lobby debate by settling three details in advance: the Tour or event, the vehicle class, and whether the group is playing competitively or casually. **Star Wars: Galactic Racer** includes landspeeders, speeder bikes, skim speeders, and separate podracer events. Do not assume a speeder setup transfers directly to a pod grid. Read the event card and use the required category.

If the group is learning a track, choose one clean objective such as finishing safely or identifying the boost route. If the goal is a rivalry challenge, agree on that before entering. A six-player race can create more traffic and more contact points, so an informal “first lap is for learning” rule can make the first run less chaotic.

## Understand the mid-Tour credit change

The QoL update increased credits awarded to players who join mid-Tour in online multiplayer from **4,000 to 6,000**. This improves the catch-up entry point for a friend who arrives late. It does not mean every player receives 6,000 credits after every race or that a mid-Tour joiner has identical campaign progress to the host.

When someone joins late, check the garage and current Tour state before choosing upgrades. The credit award helps them participate, but it is still useful to choose a practical setup for the remaining events. Spend only after checking what track and vehicle class come next. If the group is close to finishing the Tour, saving those credits for a later session may make more sense than buying a rushed part.

## Choose a keyboard preset that fits your hands

The update adds multiple keyboard layout presets to support **AZERTY** keys and left- or right-handed play. Open the input settings before a race and select the layout that matches your keyboard and preferred hand position. Then test steering, acceleration, braking, and boost in a low-pressure event or menu context.

The announcement says full key rebinding is planned for a future update; it is not included in this preset change. A preset can make the controls more usable, but it may not match every player's preferred arrangement. If a key is not configurable yet, select the closest available preset and report the specific binding that prevents play. Do not follow an old guide that assumes free remapping has already shipped.

## Make spectator view and connection issues easier to diagnose

The update includes multiplayer spectator-camera transition tidy-ups, party stability fixes, and a PS5 connection fix. If the camera transition still looks odd, note which event ended, when the view changed, and whether the problem followed a disconnect. For a connection failure, record the platform, party size, and whether the player could join another online session.

The patch also fixes a crash related to **AMD Frame Interpolation**. If you previously encountered that crash, update the game and retest with the same graphics setting before replacing drivers or editing files. If it continues, report the graphics card, driver, and whether Frame Interpolation was enabled. The patch note identifies a particular crash condition, not a universal graphics compatibility guarantee.

## A clean six-player session checklist

Before the group starts, update and relaunch; verify campaign customization; choose the Tour and vehicle class; confirm that all six players are in the online party; and let late arrivals check their 6,000-credit entry before buying. Keyboard players should set a layout preset and test it before the start. After a race, note any connection or spectator issue while the sequence is fresh.

The expanded party cap is most useful when the group treats the Tour as a shared sequence rather than a random lobby. Prepare the garage once, communicate the next event, and keep technical reports specific. For the solo campaign loop, use the [first Tour plan](/tips/galactic-racer-first-tour-plan/) and the [Arcade practice guide](/tips/galactic-racer-arcade-practice-guide/).
