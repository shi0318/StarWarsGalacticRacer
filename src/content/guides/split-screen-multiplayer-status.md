If you are asking whether **Star Wars Galactic Racer** supports local split-screen multiplayer, the careful answer is: **local co-op and split-screen are not currently confirmed**. The current verified feature set gives us a release date of **October 6, 2026**, a **PC** release, a **solo campaign**, and **online multiplayer**. It does not confirm a local multiplayer mode.

## What is confirmed for Star Wars Galactic Racer

- Planned release date: October 6, 2026.
- Platform currently identified: PC.
- Solo campaign.
- Online multiplayer.

The confirmed list establishes that Star Wars Galactic Racer combines a solo campaign with online multiplayer. It does not tell us that the online feature can be played on one screen or by multiple people sharing one device.

## Is local co-op confirmed?

No local co-op or split-screen mode is confirmed in the current feature information. That is an evidence boundary, not an absolute claim that the shipped game can never include it. The status should be revisited when the final release build or a new official feature announcement provides a direct answer.

After October 6, 2026, check the actual release version for a local or couch-play option and record the exact wording if one appears. Until then, use online multiplayer as the confirmed multiplayer category and do not promise same-device play.
