A 7.5-hour negative file stacks three launch bugs: **HDR is washed out and blown out at once**, menus look awful, daytime is blinding; **soft-locking black screens between races** force a restart; and **save progress corrupted** after eight hours and championships won. That is not rubber-band AI. That is not a missing private lobby.

The launch hotfix raised the driver floor and made DLSS options more stable. It did not publish an HDR rewrite. If the image is unplayable, turn HDR off in Windows and in-game before you refund. If the black screen is between races, wait out the shader rebuild on first boot after a driver update — the hotfix warned that boot takes longer while the cache rebuilds.

## Order of checks

- Driver hotfix first. See [driver hotfix](/driver-hotfix/).
- HDR off. Daytime snow and desert are the worst offenders.
- If a black screen persists after a restart, it is a race-transition hang, not a takedown cam. See [takedown camera](/tips/takedown-camera/).
- A corrupted championship file is the expensive one. Cloud is on the store page. It does not promise a rollback. Copy the save folder before you launch again.
