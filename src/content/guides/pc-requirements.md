Steam now lists both tiers. Both tiers are on the store page for the shipped game.

## Minimum

| Part | Spec |
| --- | --- |
| OS | Windows 10 |
| CPU | Intel Core i5-8400 / AMD Ryzen 5 2600 |
| RAM | 12 GB |
| GPU | RTX 2060 / Intel Arc A580 / RX 5600 XT 6 GB |
| Storage | 50 GB, SSD required |

## Recommended

| Part | Spec |
| --- | --- |
| CPU | Intel Core i7-10700 / AMD Ryzen 7 3700X |
| RAM | 16 GB |
| GPU | RTX 3060 Ti / Intel Arc B580 / RX 6700 XT |
| Storage | 50 GB, SSD required |

The SSD line is in both tiers. A 50 GB hard drive does not meet the page.

## What else the store page commits to

The game launched with NVIDIA DLSS 4.5. That is a first-party note, not a review claim. The page is Windows-only. There is no Mac or Linux tab. Player reports say the build runs on SteamOS; that is not an official Linux listing, and it is not a reason to ignore the Windows GPU tier.

If the install fails the space check, the [download page](/download/) has the store link and the price. It will not get smaller.
