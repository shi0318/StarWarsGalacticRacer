Derven Acos is not a planet the League borrowed. It is an arena built for the circuit. The story trailer calls it the test that combines every planetary condition from the tour. The launch announcement says multiplayer runs end in a showdown there. Both point at the same place: this is the gauntlet, not a scenic extra.

## What "every condition" means in practice

You have already been asked to survive, separately:

- wreckage and dust on Jakku
- ice and heat tunnels on Ando Prime
- draft blindness on Crait
- acid on Sentinel One
- lava heat on Lantaana

Derven Acos is where a build that cheated one of those checks gets exposed. Nerves and a tuned speeder, in the trailer's wording. If resilience is still zero, you already know which check fails.

## How to arrive

- Finish the planets as build checks. Do not save every credit for a cosmetic livery.
- Bring a landspeeder if the tour still matters. Bring the bike only if the earlier planets were clean.
- A wreck-out here ends the tour the same way a wreck-out on Jakku does. The difference is how long it took to get back.

There is no public corner map. Learn it the way you learned the others: one careful pass, then the ramjet.
