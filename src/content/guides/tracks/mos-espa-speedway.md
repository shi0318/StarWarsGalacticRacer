**Mos Espa Speedway** is the main podracing circuit on **Tatooine** and the track most players mean when they search for "the Tatooine race". It is a **12.6 km circuit**, run over **3 laps** in its standard form, and it is **podracer only**. Speeders never race here.

The numbers explain how it drives. A **93 m elevation range** is flat by this game's standards; Ice Field Circuit swings over 300 m and the Derven Acos finale over 1,100 m. Mos Espa does not test hills. It tests width and line choice: **78 m of average width** and **nine alternative lines** give a pack of pods room to spread, so most of the race is passing.

## Layouts

| Layout | Direction | Where it is used |
| --- | --- | --- |
| Podracer | Forward | Campaign memory races |
| Special | Forward | Arcade events |
| Podracer | Reverse | Campaign memory races |

The reverse layout keeps the same 12.6 km length, so lap times compare directly. What changes is where you brake: the corners you took at the end of a straight now come at the start of one.

## Events on Mos Espa Speedway

Six events use the circuit:

| Event | Mode |
| --- | --- |
| King of the Racers | Arcade race |
| Twin Sun Flight | Arcade time trial |
| A Pretender Approaches | Memory |
| Day of the Flame Vents | Memory |
| Memories of Mos Espa | Memory |
| The Harder They Fall | Memory |

The four **memory races** are the campaign's podracing chapter, which Sebulba opens with a practice demand. If you can only see the speeder garage, open **Arcade**. **King of the Racers** and **Twin Sun Flight** are there from the start. See [Tatooine](/tracks/tatooine/) for how the pod grid unlocks.

## How to drive it

1. **Use the width.** With nine alternative lines, the inside line is rarely the only fast one. Pick the line with clean air, not the one the pod ahead is on.
2. **Pods are wider than they look.** The energy binder between the engines catches walls and rivals. Leave a pod's width on the inside of every corner.
3. **Learn it once forward before you race reverse.** Two of the four memory races use one direction and two the other. Practice in **Twin Sun Flight**; a time trial has no pack to hide your mistakes.

The other Tatooine track, **Hunk of Junk**, is a 12.1 km single-lap point to point that only appears in the campaign.
